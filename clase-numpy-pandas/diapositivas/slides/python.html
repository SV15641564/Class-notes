Calentamiento · Python en 10 minutos

Cuatro ideas bastan para empezar

1 · Variable

Una caja con una etiqueta donde guardo un dato.

precio

2500

precio = 2500
print(precio)

2500

2 · Lista

Varios datos en fila; empieza en 0 y -1 es el último.

3.5

0

4.0

1

2.8

2

notas = [3.5, 4.0, 2.8]
print(notas[0], notas[-1])

3.5 2.8

3 · Bucle for

Repite una acción con cada elemento, uno por uno.

3.5

×2

→

7.0

for n in notas:
    print(n * 2)

7.0
8.0
5.6

4 · Comparar

La respuesta es siempre verdadero o falso.

= guarda

== pregunta

total = 2500 * 4
total > 5000
total == 10000

True
True

Para ejecutar una celda: Shift + Enter. Las celdas corren en orden; si te saltas una, la siguiente puede fallar.

NumPy y pandas · 04 / 25 · notebook: «Python en 10 minutos» (código resumido)

Esta diapositiva es solo para grupos que nunca han programado (10 min). Va con el notebook abierto en la sección «Python en 10 minutos»: ejecuta cada celda y pide que predigan el resultado antes. 1) Variable: una caja con etiqueta; el signo = significa «guarda», no «es igual a». 2) Lista: varios datos entre corchetes; el primero está en la posición 0, por eso notas[0] da 3.5 y notas[-1], el último, da 2.8. 3) Bucle for: repite lo indentado con cada elemento: imprime 7.0, 8.0 y 5.6. Anuncie: «dentro de un rato NumPy hará esto sin escribir el bucle». 4) Comparar: total = 2500 × 4 = 10000; total > 5000 es True y total == 10000 también; = guarda y == pregunta. Cierre con la franja oscura: Shift + Enter y el orden de las celdas. Si el grupo ya sabe esto, sáltala.
