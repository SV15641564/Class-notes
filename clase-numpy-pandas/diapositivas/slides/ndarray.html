NumPy y pandas · 06 / 25

Muestre primero el dibujo y luego el código. Tres ideas: (1) el arreglo guarda valores del mismo tipo (dtype); (2) cada casilla tiene una posición que empieza en 0; (3) shape es (filas, columnas): para un arreglo de una dimensión es solo (5,). arange es como range pero devuelve un arreglo; linspace reparte N puntos equidistantes. Error típico: creer que shape (5,) y (5,1) son lo mismo; lo veremos en broadcasting. Pregunta: ¿cuántas casillas tiene una matriz de forma (2, 3)? Seis.
